## 💡 Навыки

### React и Next.js
- Компонентный подход, переиспользуемые компоненты
- Хуки (`useState`, `useEffect`, `useMemo`, `useCallback`, `useRef`), собственные хуки
- Context API, Redux Toolkit
- Next.js App Router, серверные и клиентские компоненты
- Маршрутизация, динамические страницы

### TypeScript и JavaScript
- Современный JavaScript (ES6+): деструктуризация, модули, async/await, Promise
- Типизация компонентов, пропсов, API-ответов
- Интерфейсы, дженерики, utility-типы

### Вёрстка
- Адаптивная и кроссбраузерная вёрстка, mobile-first
- Flexbox, CSS Grid, анимации и переходы
- Tailwind CSS, SCSS, CSS Modules
- Pixel-perfect вёрстка по макетам из Figma
- Семантичная разметка и базовая доступность (a11y)

### Работа с данными
- REST API
- Обработка состояний загрузки, ошибок и пустых данных
- Формы и валидация (React Hook Form)
- Базы данных PostgreSQL и SQLite

### Качество и деплой
- Git: ветки, pull request, разрешение конфликтов
- ESLint и Prettier для единого стиля кода
- SEO-оптимизация: метатеги, Open Graph, sitemap
- Оптимизация производительности: lazy loading, оптимизация изображений
- Деплой на Vercel и на собственный сервер
